Power BI 三页看板 · 逐步操作手册

Online Retail 项目 · 每一个视觉对象的精确点击路径｜2026.09

开工前的三条铁律

  1. 新建视觉对象前，先点一下画布空白处（或按 Esc），确保没有对象被选中。选中状态下点图表图标 = 把当前对象转换成新类型，原来的图就没了。
  2. 做错了按 Ctrl+Z 撤销；每做完一个视觉对象按 Ctrl+S 保存一次。
  3. 本手册里的字段名以你的导出文件为准：retail_clean（交易明细）、rfm（客户分层，一人一行）、retention（留存矩阵）、日期表。名字不一样就找对应的那个。
必做前置（第一页折线变直线的根因）：确认 日期表[Date] 与 retail_clean[订单日期] 已建立一对多关系（模型视图里是实线）。没有这步，所有按时间的图表都会退化成一条水平线。

度量值全集（一次性建好，三页通用）

菜单栏 建模 → 新建度量值，逐条粘贴。建好后它们会出现在字段列表上方带计算器的图标。

总销售额 = SUM('retail_clean'[TotalPrice])
订单数   = DISTINCTCOUNT('retail_clean'[InvoiceNo])
客户数   = DISTINCTCOUNT('retail_clean'[CustomerID])
客单价   = DIVIDE([总销售额], [订单数])

-- 第1页：趋势与时间对比
上月GMV  = CALCULATE([总销售额], PREVIOUSMONTH('日期表'[Date]))
环比增速 = DIVIDE([总销售额] - [上月GMV], [上月GMV])
去年GMV  = CALCULATE([总销售额], SAMEPERIODLASTYEAR('日期表'[Date]))
同比增速 = DIVIDE([总销售额] - [去年GMV], [去年GMV])

-- 第2页：分层相关
分层GMV  = SUM('rfm'[Monetary])
人均R    = AVERAGE('rfm'[Recency])
人均F    = AVERAGE('rfm'[Frequency])
人均GMV  = AVERAGE('rfm'[Monetary])
复购率   = DIVIDE(CALCULATE(COUNTROWS('rfm'), 'rfm'[Frequency] >= 2), COUNTROWS('rfm'))
重要保持客户人数 = CALCULATE(COUNTROWS('rfm'), 'rfm'[Segment] = "重要保持客户")
同比增速 因为数据只有一年，2011 年的月份才有值、2010 年 12 月为空——正常，不用管。第 1 页想用就用一个卡片展示，不用就先留着。

第 1 页 · 销售总览

1.1 四个 KPI 卡片（总销售额 / 订单数 / 客户数 / 客单价）

  1. 1点画布空白处 → 可视化面板点「卡片」图标（数字 123 那个）。
  2. 2右侧字段面板勾选 总销售额，卡片即显示。
  3. 3卡片处于选中状态 → 按 Ctrl+C、Ctrl+V 复制三份，拖到右侧并排。
  4. 4三个副本分别勾选 订单数、客户数、客单价。
  5. 5统一格式：选中卡片 → 格式（刷子图标）→ 视觉效果 → 标签 → 标题，关闭标题或改成"总销售额"等；常规 → 效果 → 背景 可加浅色底。
小技巧：想让数字显示为"6.59 百万"，选中卡片 → 格式 → 标签 → 显示单位 → 百万。

1.2 月度 GMV 折线图关键

  1. 1点画布空白处 → 点「折线图」。
  2. 2X 轴：从 日期表 拖 Date（拖字段本身，不要拖"Date 层次结构"）。
  3. 3点 X 轴字段旁的下拉箭头 → 选择 Date（月），即显示粒度设为"月"。
  4. 4Y 轴：拖度量值 总销售额。
  5. 5格式 → 常规 → 标题改成"月度销售额趋势（英镑）"；线条 里可开启标记点（小圆点）更易读。
正确结果：13 个点，从 2010年12月 到 2011年12月，9~11 月明显爬升，最后一点骤降（该月只有 9 天）。
如果 X 轴只有 January~December 12 个点、且没有年份 → 说明你拖了层次结构里的"月份"层，跨年同月会被合并，改回本步第 3 点的做法。

1.3 国家销售额 TOP10（横向条形图）

  1. 1点空白 → 点「簇状条形图」（横向柱子）。
  2. 2Y 轴：retail_clean[Country]；X 轴：总销售额。
  3. 3右侧筛选器面板 → 把 Country 拖进"此视觉对象上的筛选器" → 筛选类型选前 N 个 → 输入 10 → 把 总销售额 拖进"依据值"。
    （没有"前 N 个"选项就选"高级筛选"，条件设为：显示项目 前 10 项 按 总销售额 降序。）
  4. 4标题改为"销售额 TOP10 国家"。
如果想做地图：点「填充地图」，位置放 Country、颜色饱和度放 总销售额。缺点是 Power BI 可能把某些国家名识别错，条形图更稳，两者选一个即可。

1.4 星期 × 小时 销售热力图

  1. 1先让星期显示中文：数据视图 → 选中 retail_clean → 建模 → 新建列：
星期 = SWITCH('retail_clean'[Weekday],
        0,"周一",1,"周二",2,"周三",3,"周四",4,"周五",5,"周六",6,"周日")
  1. 2（可选）新建排序列，避免"周一/周三/周二"乱序：星期序号 = 'retail_clean'[Weekday]，然后选中 星期 列 → 列工具 → 按列排序 → 星期序号。
  2. 3点空白 → 点「矩阵」图标。
  3. 4字段配置：行 = 星期，列 = Hour，值 = 总销售额。
  4. 5上色：格式 → 单元格元素 → 展开"背景色" → 点 fx（条件格式） → 格式样式选数据色阶 → 最小色设浅黄、最大色设深红 → 确定。
  5. 6标题改为"星期 × 小时 销售热力图"。
预期看到周六、周日整行是空的（这家公司周末不处理订单）。这是你 EDA 里最有价值的发现，截图时保证它在画面里。

1.5 销量 TOP10 商品

  1. 1点空白 → 点「簇状条形图」。
  2. 2Y 轴 = Description，X 轴 = Quantity 的求和（直接拖 Quantity 字段，默认就是求和）。
  3. 3同 1.3 第 3 点，设"前 10 个 按 Quantity 求和"。
  4. 4标题"销量 TOP10 商品"。

1.6 切片器（国家 / 月份）

  1. 1点空白 → 点「切片器」（漏斗图标）。
  2. 2字段拖 Country → 右上角点下拉箭头把样式改为下拉（省地方），开启"全选"。
  3. 3再建一个切片器，字段拖 日期表[Date] → 样式改为介于（时间滑块）。如果只想按月份选，拖 OrderMonth 并设为"下拉"。
切片器默认不联动其他视觉对象。选中切片器 → 菜单栏格式 → 编辑交互，页面上的每个图右上角会出现小图标，点筛选图标（漏斗的那个）让它们被联动。这是"交互式看板"必须的。

第 2 页 · 用户分层最重要

底部页面标签旁点 ➕ 新建第 2 页，右键标签可重命名为"用户分层"。

2.1 客户价值散点图

  1. 1点空白 → 点「散点图」。
  2. 2从 rfm 表拖字段：图例 = Segment；X 轴 = Recency；Y 轴 = Frequency；大小 = Monetary。
  3. 3关键：点 X 轴字段旁下拉 → 聚合改为平均值；Y 轴同样改为平均值；大小可保持求和。
  4. 4标题"客户价值分布（气泡大小 = 消费金额）"。
不改聚合的话，Recency 会被求和，X 轴出现几万天的怪值，图会挤成一条线。这是这一步唯一的坑。

2.2 分层人数 vs GMV 组合图（帕累托）面试主图

  1. 1点空白 → 点「折线和簇状柱形图」。
  2. 2X 轴 = rfm[Segment]。
  3. 3列 y 轴 = rfm[CustomerID]，确认聚合是计数(非重复)；若显示为"求和"，点下拉改成计数。
  4. 4行 y 轴 = 度量值 分层GMV。
  5. 5图表右上角 … → 排序方式 → 分层GMV，并设为降序。
  6. 6格式 → 线条 → 线条形状 开启标记；标题"各分层人数与 GMV 贡献"。
这张图出来后应该看到：柱子从左到右递减、折线在前两类陡升后迅速走平——这就是帕累托，和你 Python 里 22.8%/69.5% 的数字互相印证。

2.3 分层明细表

  1. 1点空白 → 点「表」图标。
  2. 2依次拖入：Segment、CustomerID（计数）、人均R、人均F、人均GMV、分层GMV。
  3. 3右键列头重命名：CustomerID 的计数改成"人数"。
  4. 4按分层GMV 降序排（点列头箭头）。
这张表的数字必须和你 Python 跑出的 summary 对得上（重要价值客户 975 人、人均 GMV 约 4700）。对不上说明数据导入有问题，回头检查。

2.4 两个关键卡片

  1. 1卡片一：勾选度量值 复购率 → 格式 → 标签 → 改为百分比显示（选中字段后列工具里设格式）。
  2. 2卡片二：勾选 重要保持客户人数（你的数据里是 11 人，如实显示即可）。

2.5 Segment 切片器（交互演示用）

  1. 1点空白 → 点「切片器」 → 字段拖 rfm[Segment]。
  2. 2格式 → 视觉效果 → 切片器设置 → 样式选磁贴或下拉，方向改为水平。
  3. 3同样用格式 → 编辑交互打开对散点图、明细表的联动。
面试现场就演示这个：点一下"重要价值客户"，散点图和表格瞬间只剩这一类人。这一下比任何静态截图都说明"我会用 BI 做交互式看板"。

第 3 页 · 留存与商品

3.1 Cohort 留存热力矩阵简历支撑图

  1. 1新建第 3 页 → 点空白 → 点「矩阵」。
  2. 2行 = retention[CohortMonth]；列 = retention[CohortIndex]；值 = retention[Retention]（聚合选平均值）。
  3. 3选中值字段 → 列工具 → 格式 改为百分比、小数位 1 位。
  4. 4上色：格式 → 单元格元素 → 背景色 fx → 数据色阶 → 最小色浅蓝、最大色深蓝 → 确定。
  5. 5标题"同期群留存矩阵（行 = 首购月，列 = 第 N 个月）"。
右下角空白三角是正常的（数据右截断）。第 0 列必须全是 100%。次月留存那一列平均约 20.3%，和简历数字一致。

3.2 商品销售额 TOP20（带累计占比）

  1. 1点空白 → 点「折线和簇状柱形图」。
  2. 2X 轴 = Description；列 y 轴 = 总销售额。
  3. 3筛选器设"前 20 个 按 总销售额"。
  4. 4（进阶，可做可不做）新建度量值并拖到行 y 轴：
累计GMV =
VAR cur = [总销售额]
RETURN CALCULATE([总销售额],
    FILTER(ALLSELECTED('retail_clean'[Description]), [总销售额] >= cur))
累计 GMV 的 DAX 计算量较大，数据量小（4 千客户）可以接受，但如果你电脑上卡顿，直接删掉这根线，只保留柱状图即可——不影响简历。

3.3 商品价格带分布（可选）

  1. 1点空白 → 点「簇状柱形图」。
  2. 2X 轴 = UnitPrice → 点 X 轴字段下拉选新建组 → 箱(Bin)，箱大小填 2（即 0~2、2~4 英镑一档）。
  3. 3Y 轴 = 订单数 或 Quantity 求和。
  4. 4标题"商品价格带分布（英镑）"。

收尾：统一风格 + 导出截图

统一外观（三页都设一遍）

  • 视图 → 主题（新版在"视图 → 主题"或"自定义当前主题"）可一次性统一配色；不用主题就手动把主要颜色改成 #1f5fa9（深蓝），与你的简历配色一致。
  • 视图 → 网格线 打开，"对齐到网格"让图表边缘整齐。
  • 每个视觉对象都改标题，写清单位（英镑、件、人）。

导出

  • 文件 → 另存为 PDF：一次导出全部三页，最省事，直接能放进作品集。
  • 或者用 Windows 截图工具（Win+Shift+S）逐页截，再用 PPT 把三张拼成一页。
  • .pbix 源文件存放在 powerbi/retail_dashboard.pbix，方便以后改。
截图后发我，我帮你判断哪张最适合放进简历作品位。放简历的图要有三个特点：有业务洞察（比如周末空白、帕累托折线）、数字和简历文案对得上、配色和简历一致。

故障速查表

现象原因与解法
折线是一条水平直线日期表没建关系，或 InvoiceDate 带时间匹配失败。给 retail_clean 新建列 订单日期 = INT([InvoiceDate]) 改成日期类型后再建关系
点图表图标后原来的图没了对象处于选中状态，点图标 = 转换类型。按 Ctrl+Z，下次先点空白处
X 轴顺序乱（2011-01 后接 2011-10）用了文本型 OrderMonth。改用日期表 Date 并把粒度设为"月"
散点图所有点挤在一条线上聚合是"求和"，改成"平均值"
切片器点了没反应格式 → 编辑交互 → 给目标图点"筛选"图标
卡片数字显示为 6590000格式 → 标签 → 显示单位 → 选"百万"
矩阵里空白一片值字段聚合不对（应为平均值），或 retention 表的 CohortMonth 被识别成数字——改成文本即可
